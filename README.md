# Curso contenedores

![](img/mbit-logo.svg)

Esta documentación está en formato [mdBook](https://rust-lang.github.io/mdBook/).

Para compilarla necesitas instalar:
- mdBook
- mdbook-mermaid (para los diagramas)

Una vez instalado, puedes compilar la documentación ejecutando `mdbook build` en la raíz del proyecto.

La documentación generada se encontrará en la carpeta `book`.

Si quieres ver la documentación en un servidor local, puedes ejecutar `mdbook serve` y acceder a [http://localhost:3000](http://localhost:3000).
