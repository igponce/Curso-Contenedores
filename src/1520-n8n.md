# Orquestador n8n

N8N es un orquestador de flujos de trabajo basado en Node.js.

Se utiliza mucho para orquestar flujos de trabajo entre distintos servicios, y para automatización de tareas basado en agentes (Claude, OpenAI, etc.).

Vamos desplegar n8n a partir de contenedores:

Objetivos:

1. Desplegar n8n a partir de un contenedor básico.
2. Desplegar una base de datos postgres.
3. Configurar n8n para que pueda mantener su configuración.
4. Crear un flujo de trabajo en n8n que almacene datos en una base de datos. 
5. Configurar n8n para que utilice la BBDD postgres como memoria de chat.
  (pista: ¿qué dirección IP tiene la BBDD de postgres?)
