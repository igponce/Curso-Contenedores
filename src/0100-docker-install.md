
# Instalación

Docker tiene varios productos:
- [Docker Engine](https://docs.docker.com/engine/install/
  - Antigua versión _Community Edition (CE)_
  - Core de docker
  - No tiene interfaz gráfica
  - Docker Desktop
    - Tiene interfaz gráfica además de los comandos 'cli' tradicionales.
    - Sistemas soportados
      - [Mac (ARM)](https://docs.docker.com/desktop/setup/install/mac-install/)
      - [Linux (i386/ARM)](https://docs.docker.com/desktop/setup/install/linux/)
      - [Windows (i386/ARM)](https://docs.docker.com/desktop/setup/install/windows-install/)
